ovspatialquery#

ovspatialquery is a C library with a Python package for spatial queries: raycasts, sphere and box sweeps, overlaps, and bounding-box pairs over geometry a simulation publishes. It runs on the CPU with no GPU required, and on CUDA devices when you ask for it. Geometry comes from an ovstage stage or from arrays you supply. It performs no dynamics simulation.

Several engines, sensors, and tools can query the same published geometry through it, so none of them has to keep its own scene-query structure synchronized with the simulation.
